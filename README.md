# NutriApp 

NutriApp es una aplicación web diseñada para ayudar a los usuarios a gestionar su nutrición y hábitos alimenticios. Permite registrar alimentos, comidas y seguimiento de peso, proporcionando una visión integral de la salud nutricional del usuario.
